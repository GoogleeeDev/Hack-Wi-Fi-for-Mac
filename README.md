# ⚡️ Wi-Fi Hack For Mac by Googleee ⚡️

> **Описание:** Автоматизированный интерактивный комбайн для проведения аудита безопасности беспроводных сетей в операционной системе macOS. Программа снабжена интуитивно понятным текстовым интерфейсом, полностью очищает Терминал от системного мусора при переходах и предоставляет удобное управление через цифровое меню.

---

## 📂 Структура репозитория

```text
Hack Wi-Fi for Mac/
├── .gitignore               # Исключение временных файлов трафика из Git

│   └── config.example.env   # Шаблон конфигурации путей к файлам
└── src/
    └── script.sh            # Главный исполняемый скрипт комбайна
```

## 🎮 Визуальный функционал: Интерфейс и экраны программы

Интерфейс приложения разработан в классическом стиле интерактивных консольных утилит. При запуске скрипт автоматически растягивает окно Терминала macOS до фиксированного размера **120 на 40 символов**, обеспечивая ровное отображение таблиц и графики.

Программа состоит из следующих визуальных экранов:

### 📺 Экран 1. Главное меню проекта
Это стартовый экран приложения, который встречает пользователя при каждом запуске.
*   **Что отображается:** 
    *   В самом верху выводится массивный, стилизованный текстовый ASCII-логотип **`HACK WI-FI MAC by Googleee`** синего цвета.
    *   Ниже отображается аккуратный блок **«ВЫБОР ФУНКЦИЙ»**, оформленный в виде таблицы.
    *   Пользователю доступны четыре интерактивных пункта: переход к выбору файлов, меню очистки, информационная справка, настройки директорий и кнопка выхода (`q`).

### 📺 Экран 2. Выбор файла Wi-Fi захвата (Шаг 1/2)
Визуальный модуль для локализации записанного беспроводного трафика.
*   **Что отображается:**
    *   На экране появляется интерактивная таблица **«Доступные файлы беспроводной диагностики»**.
    *   Скрипт выводит список всех найденных в системе файлов захвата трафика `.pcap`. Каждая строчка содержит порядковый номер, оригинальное имя файла и точную дату/время его создания.
    *   Внизу таблицы отображается кнопка быстрого возврата обратно в Главное меню (`[b]`).

### 📺 Экран 3. Список доступных сетей и хэндшейков (Шаг 2/2)
Экран, который появляется сразу после выбора файла трафика.
*   **Что отображается:**
    *   Вверху выводится зеленое подтверждение с именем файла, который сейчас находится в обработке.
    *   По центру отрисовывается таблица **«Список доступных хэндшейков для взлома»**. 
    *   В таблицу выводятся только те Wi-Fi сети, для которых в файле трафика был успешно зафиксирован факт авторизации (валидный хэндшейк). Пользователь видит имя сети (`ESSID`), её MAC-адрес (`BSSID`) и тип шифрования.
    *   Интерфейс предлагает ввести номер строки нужной сети для начала проверки.

### 📺 Экран 4. Выбор режима атаки
Финальный экран перед запуском перебора паролей.
*   **Что отображается:**
    *   Пользователю выводится цветное меню **«ВЫБЕРИТЕ РЕЖИМ АТАКИ»**.
    *   На выбор предоставляются три графических пункта: запуск по Умному Мега-Словарю, Тотальный брутфорс (автоматическая генерация 8-значного буквенно-цифрового словаря) или Расширенный маска-брутфорс (база длинных паролей на основе СНГ/Казахстанских имен, фамилий и номеров телефонов).
    *   После выбора режима экран полностью очищается, блокируя вывод сотен строк лишнего системного шума, и выводит аккуратную бегущую строку процесса проверки.

### 📺 Экран 5. Показать информацию и рекомендации
Изолированное справочное окно для помощи пользователю.
*   **Что отображается:**
    *   На экране открывается структурированное оглавление **«ИНФОРМАЦИЯ И РЕКОМЕНДАЦИИ ПО АУДИТУ»**.
    *   Текст по пунктам объясняет базовые правила работы: как правильно зафиксировать карту Mac на канале сети, как вызвать переподключение телефона для захвата ключей и где хранятся системные логи.
    *   Возврат в Главное меню происходит по нажатию клавиши Enter.

### 📺 Экран 6. Меню настроек директорий
Панель управления путями данных комбайна.
*   **Что отображается:**
    *   Выводится таблица **«НАСТРОЙКИ ДИРЕКТОРИЙ»**.
    *   В реальном времени отображаются текущие папки, в которых программа ищет дампы трафика и словари паролей. Пользователь может визуально контролировать, куда сохраняются данные.

### 📺 Экран 7. Меню очистки системных файлов
Модуль для поддержания чистоты на жестком диске.
*   **Что отображается:**
    *   Красное предупреждающее меню **«ОЧИСТКА СИСТЕМНЫХ ФАЙЛОВ»**.
    *   Пользователю предлагается выбрать один из двух визуальных вариантов: стереть временные словари только внутри папки проекта, либо полностью вычистить скрытую системную папку Mac от старых гигабайтных дампов трафика.

## 🛠 Какие программы понадобятся (Зависимости)

Для корректного отображения и работы комбайна в системе должны быть установлены следующие компоненты:
1. **Менеджер пакетов Homebrew** — необходим для управления консольными утилитами на macOS.
2. **Git** — консольный клиент для клонирования репозиториев.
3. **Aircrack-ng** — основной набор утилит для анализа беспроводных сетей и парсинга хэндшейков.
4. **Crunch** — генератор словарей паролей по заданным шаблонам и маскам.
5. **Словари SecLists** — профессиональный набор словарей для тестирования безопасности. Папка `SecLists` должна быть загружена в вашу домашнюю директорию пользователя (`~/SecLists`).

## 🚀 Инструкция по запуску комбайна

1. Перейди в папку с проектом через Терминал:
   ```bash
   cd "Hack Wi-Fi for Mac"
   ```
2. Дай файлу `script.sh` права на запуск в системе:
   ```bash
   chmod +x src/script.sh
   ```
3. Запускай комбайн:
   ```bash
   bash src/script.sh
   ```
